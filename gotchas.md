# Architecture lessons

- For SharpRail, upstream is [JetBrains/thinkrail:main](https://github.com/JetBrains/thinkrail/tree/main).

- A host/client request for this maquette means a C# host as well as a C# client. Do not infer reuse of the reference's Bun host or Pi integration. Embedded calls are direct; gRPC is only the remote adapter.
- A performance-research maquette request authorizes implementation and optimization checks, not benchmark runs. Run measurements only when explicitly requested; when asked to show the app, leave the packaged GUI running.
- Project readiness must be established before projecting restored document tabs. Test a fresh window/profile restoration; switching back in an existing window can hide startup bugs behind cached content.
- Keyboard overflow needs a focusable result list and Enter activation from search. Test duplicate titles by resource path; correct filtering alone does not prove keyboard selection.
- Capture only the prototype's window ID. Screen-region captures can include private apps when the user switches windows; remove an accidental capture and do not reuse its content.
- A custom subclass of an Avalonia templated control must select its base control's style key when reusing that template. Parsed/rendered Markdown does not prove scrolling; verify wheel input changes the offset of a document larger than its viewport.
- Pane context actions must be reachable by right-clicking tabs, unused header space and empty pane content. Menu construction alone is insufficient; test right-button input, menu opening, and canonical layout changes.
- Fixed-height tab chrome needs a fixed label size independent of document text preferences. Leave room for italic preview glyph overhang inside the measured label box.
- Match the reference title bar's actual controls. Do not add project or layout icons merely because their actions are useful; keep those actions in the existing panel, shortcuts or context menus.
- A custom title bar must handle pointer gestures on its full painted surface, including blank space and margins. Attaching move/zoom only to an inner grid without a background misses those clicks. Preserve button input and verify native double-click zoom as well as headless routing.
- Reselecting the active tab must advance navigation without rebuilding the tab strip. Rebuilding between clicks can leave the second native mouse press hitting unarranged replacement controls. Headless clicks that pump layout between presses conceal this failure; include a native sequence and a test without an intermediate layout pump.
- Use the reference icon asset for branch indicators; a Unicode branch-like symbol changes shape with the font and does not match the UI. Keep the branch name as plain text beside the icon.
- Build fractional grid sizes with numeric GridLength values. Interpolated definition strings use the current culture; decimal commas become extra rows or columns. Verify actual split geometry under a decimal-comma culture, including nested horizontal and vertical splits.
- A request for C# and Avalonia does not mean every control must be constructed in C#. Use compiled XAML for static layouts, styles and templates; reserve procedural construction for genuinely dynamic UI. Do not claim C# construction is inherently faster than compiled XAML.
- Follow the reference component for small interactions: tab search is a compact anchored popover shown only on actual overflow, not a modal dialog. Specs shorten spaced em/en dashes to middle dots and reveal role tags on hover or focus.
- Embedded Markdown controls default to a bottom-edge baseline. Supply the label's measured text baseline and test its alignment with the paragraph at multiple font sizes.
- Headless interaction tests must run the dispatcher event loop and render ticks before hit testing. Resolve rebuilt controls again, move the pointer off old tooltips, and wait for the requested selection rather than merely an already-open tab.
- A pane can have an effective selected tab without an explicit selection entry after a split. Preserve that effective selection when a delayed open arrives without activation. Check whether its original pane still exists before comparing its navigation clock, so a removed pane can reroute the read.
- Thinkrail's frame and selected side tools follow workspace switches; resource tabs and center selections remain workspace-specific. Verify both behaviors through actual worktree switching. Scroll clipped file rows into view before a headless click, as Playwright does.
- Mixed auxiliary tabs need the upstream's before-tool anchors. Move, hide, reveal and close must use the displayed order rather than concatenated tool/resource lists. Terminal chrome remains in scope even when terminal execution is excluded.
- Give each live test process its own log. Verify an earlier process has exited before rerunning into the same file; overlapping redirected writers can corrupt evidence even when the later test process succeeds.
- Tab tooltips must anchor to the tab bounds with the reference gap; Avalonia's pointer placement makes the label float over unrelated pane content. Verify popup geometry while moving across the trigger. Headless KeyPress sends only key-down; Space activates a Button on key-up, so send KeyRelease too when translating a full keyboard press.
- Headless Avalonia's built-in text shortcuts come from PlatformSettings.HotkeyConfiguration, not the machine's OS. Use that configuration for Select All when typing into native controls; application-specific workbench shortcuts still follow their own configured handlers.
- Multiwindow headless keyboard input follows the globally focused control, even when KeyPress names a different TopLevel. Focus the target window's control before sending its shortcut; otherwise the test can mutate the window whose active gesture it is meant to protect.
- Layout-change cancellation must release active pointer capture before rebuilding controls, without running the old resize's restore callback against the new tree. Count only active gestures for feedback; completed gestures must clear their draft before publishing a layout transition.
- Appearance checks should read ISolidColorBrush rather than require a mutable SolidColorBrush. Avalonia's shared Brushes constants are immutable; their color and alpha are still part of the same rendered contract.
- Deferred document completion is a body update, not a frame transition. Verify tab/header/separator identity and focus after a held restore read completes; the outer workbench surviving alone does not prove that interactive chrome stayed mounted.
- Escape can synchronously close and dispose a dialog on key-down. Headless key-up must not target that destroyed TopLevel; verify closure as the existing Settings tests do.
- Git E2Es cloned from upstream inherit its ignore rules; `docs/*` differs from the upstream sample-project fixture. Override only the disposable fixture's relevant rule before expecting a real untracked docs file in status.
- Avalonia context-menu ownership and popup placement are separate. Open an attached menu with its owning control; set PlacementTarget to anchor it to a sibling trigger. Passing that sibling to Open throws even when it is the intended anchor.
- Branch comparison snapshots and opened diffs must share the merge-base-to-working-tree range, including untracked files. A target-to-HEAD diff produces target-only phantom deletions and drops dirty content; verify both the list and net line counts with an advanced-target fixture.
- A failed repository probe is not automatically a non-Git folder. Recognize only Git's explicit no-repository result in a fixed process locale; preserve corrupt metadata and execution errors. Use a test-process discovery ceiling to isolate plain fixtures instead of a deliberately broken Git marker.
- Uncommitted means HEAD-to-working-tree, including staged content. Filtering only the worktree status column drops staged-only files; index-to-working-tree diffs lose staged content. Keep the selected scope in the diff tab identity even when two scopes currently use the same range.
- Scope lists and counts must share one Git range. Adding cached and working numstats counts intermediate edits twice and retains changes that cancel out. Preserve index/worktree metadata for actions while projecting paths and counts from the selected range; refresh that range after mutations.
- Commit lists and opened diffs must share the first-parent-to-commit range, with the reference's whole-tree fallback when no parent is available. Skip working status for this scope; dirty files cannot change committed content. Reject invalid/unknown IDs instead of showing a clean result.
- Comparison target, selected scope and selected commit are independent. Keep them per workspace, preserve the target on scope switches and capture all three when rejecting stale reads. A retained target must not disable pending-file staging in Uncommitted.
- Persist workspace Git selections in the profile, not in a second window-only registry. Reload catalogs from Git and verify a fresh window with a fresh ProfileStore; switching back within one window can conceal missing persistence behind cached data.

- Keep running shell build scripts stable until they exit; a shell can continue reading the file by byte offset after a long command, so editing it in place can corrupt the remaining command stream.
- MSBuild metadata inside a target can bind to an existing item from the same item list. Collect generated resources into a distinct item list and qualify its metadata when creating Content items; inspect output file types as well as copy paths.
- Restored native terminal surfaces must wait for resolved workspace identity. Building a shell while the workspace path is still empty starts an extra session in the wrong directory.
- Native input checks must dispatch through NSApplication/NSWindow after normal focus interactions. Calling keyDown or injecting PTY text directly bypasses the responder chain and cannot prove that a user can type. Tab activation must transfer focus into an embedded terminal.
- A passing injected-input test does not resolve a contradictory live user report. Check the exact running bundle and trace physical events. CGEventCreateKeyboardEvent inherits modifier state unless explicitly set; an inherited Command modifier can make a failed typing probe misleading. Unicode injection also bypasses the active keyboard layout.
- Copy NSTextInputClient insertText strings before retaining them across callbacks: AppKit can reuse and clear mutable input buffers when insertText returns. Immutable synthetic event strings missed this failure; the regression must mutate the provider's buffer before keyDown forwards it.
- Whole-tab hover belongs to the outer tab frame. Avalonia's default Button hover paints only its label presenter; suppress that inner background and verify pointer movement onto the close button and out of the tab in both themes.
- A right-clicked Avalonia ContextMenu places against its owning control even when PlacementTarget names a sibling trigger. To anchor a row menu under its kebab, let the owning control span the kebab's column and measure the opened popup against the kebab.
- Avalonia rejects `Name` changes once a control is styled; a DialogWindow built from XAML cannot be renamed after construction. Identify such windows by `Tag`.
- Rebuild rail rows only when their Git projection changes. Watcher-driven refreshes that recreate unchanged rows close open menus, drop focus and make headless clicks land on detached controls.
