# GitHub plugin

Original SharpRail implementation. This plugin invokes the user's installed GitHub CLI (`gh`); it does not bundle
GitHub source, binaries or an SDK.

`assets/github.svg` is the GitHub mark from Simple Icons (https://github.com/simple-icons/simple-icons,
`icons/github.svg`, CC0 1.0 Universal), retrieved 2026-10-28. The path data is unchanged; the `<title>` and `role`
are dropped and `fill="currentColor"` is added so the mark takes the theme colour.
GitHub is a trademark of GitHub, Inc. The mark identifies the integration and does not imply endorsement.
