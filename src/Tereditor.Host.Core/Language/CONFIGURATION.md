# Language configuration input research

Reviewed 2026-10-18. This inventory covers every **currently exposed** provider property
for all 18 catalog entries, plus SharpRail's provider-specific launch fields. It does not
claim to expose every upstream option. Settings are optional: unset uses server defaults,
while `false`, `0`, empty strings and empty arrays remain explicit values where supported.
The schema is UI metadata over the existing initialization/settings JSON, not a new store.
The portable subset of these settings may also be shared through the project's `.sharprail/language.toml`; its values validate against this typed catalog (see the language SPEC, "Project language file").

`I` means initialization options and `S` means workspace settings. Paths refer to the
workspace host, regardless of the client. Native pickers are available only to a local
embedded desktop adapter; other clients retain host-path text entry. Choosing paths for
an array appends them, leaving existing relative entries or patterns intact. Pattern,
argument and package-name arrays remain editable one-item-per-line text. Advanced JSON
preserves structured/unknown values that a named control cannot faithfully represent.

The common launch argument arrays remain arrays of individual arguments, not shell command
strings. Advanced initialization/settings values remain JSON objects. Unknown keys, custom
choice strings and structured alternatives are not rewritten by merely opening or saving the
form. Native browsing is optional; it cannot represent globs, future files, remote paths or
commands resolved through the host's PATH, so manual input remains available. Servers run from the pinned managed installation unless the host user allows PATH for that server; project files never choose executables.

This is a type/semantics review, not a new all-provider runtime acceptance claim. Tagged
sources above are used where available; SDK versions, PATH/custom executables, dependency
ranges and untagged upstream sources can differ from the bundled catalog. Changes do not
install or upgrade providers. Additional settings remain available through advanced JSON.
